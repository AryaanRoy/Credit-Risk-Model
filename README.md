# Credit-Risk-Assessment-System
Credit Risk Assessment ML Pipeline - Predicting loan default risk using ensemble models with 93% accuracy and custom financial feature engineering. Includes model comparison, visualization suite, and risk assessment reporting.

## Overview
A machine learning pipeline for predicting loan default risk using ensemble methods. The system achieves 93% accuracy and 0.93 ROC-AUC score using Random Forest classification, with comprehensive feature engineering and risk assessment capabilities.

## Key Features
- Multi-model comparison (Logistic Regression, Random Forest, Gradient Boosting)
- Custom financial feature engineering (debt-to-income ratios, interest rate indicators)
- SMOTE handling of imbalanced data
- Performance visualization suite (ROC curves, feature importance)
- Detailed risk assessment reporting

## Results
- 93% overall accuracy
- 0.93 ROC-AUC score
- 90% precision in high-risk loan detection
- Comprehensive model comparison metrics

## Technologies
- Python
- Scikit-learn
- Pandas
- Seaborn
- Matplotlib

## Usage
Clone the repository and run the main script to:
1. Load and preprocess credit risk data
2. Train and compare multiple models
3. Generate performance visualizations
4. Identify high-risk loan applications
